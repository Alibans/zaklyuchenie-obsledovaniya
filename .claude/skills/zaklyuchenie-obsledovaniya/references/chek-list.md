# Проверка перед выдачей

Пройти по пунктам и сказать пользователю, что проверено и что нашлось.

**Содержание**
- [ ] Каждая строка реестра опирается на выписку (встреча + цитата). Строк «из головы» нет.
- [ ] Каждое требование из `Входные данные` (требования, КП) есть в реестре.
- [ ] Строки — функции клиента его словами, а не объекты 1С.
- [ ] Нет «Типовое» там, где клиент не высказался.
- [ ] У новой организации нет колонки «Как сейчас» и нет «Меняем процесс».
- [ ] Правила для пользователей — «Типовое» с комментарием, а не разрыв.
- [ ] Раздел 4 содержит только доработки, «по-другому» и «меняем процесс» — и все они там есть.
- [ ] Раздел 5 — только действия Заказчика; каждый «Уточнить», «Не показывали», «Типовое, по-другому» и неназванный приоритет попал туда.
- [ ] Выводы — прозой, без подсчётов и заглушек; совпадают с реестром.
- [ ] «Дальнейшие шаги» и сроки — только согласованные на встречах.
- [ ] Одно и то же не пересказано в трёх разделах.

**Оформление**
- [ ] Собрано на бланке (`tools\build-docx.ps1`): логотип вверху, 1bit.kz внизу.
- [ ] Нумерация без пропусков и повторов.
- [ ] Нет таймкодов, внутренних пометок, слов «выписка», «черновик», «Claude», плейсхолдеров `{{…}}`.
- [ ] Нет часов и денег.
- [ ] Имена и должности — как в «О проекте».
- [ ] Открыть .docx: колонки читаются, шапка таблицы повторяется, нет пустых страниц.
