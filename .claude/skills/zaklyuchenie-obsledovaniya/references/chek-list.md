# Проверка перед выдачей

Пройти по пунктам и сказать пользователю, что проверено и что нашлось.

**Содержание**
- [ ] Каждая строка таблицы 1 опирается на выписку (встреча + цитата). Строк «из головы» нет.
- [ ] Каждое требование из `Входные данные` (требования, КП) есть в таблице 1.
- [ ] Требования — отглагольными существительными, своими словами Заказчика по смыслу, не объекты 1С.
- [ ] «Типовые средства» только там, где Заказчик согласился явно; иначе «Требует уточнения».
- [ ] Каждое «с особенностями» — пункт в разделе 4; каждая «Требуется доработка» — строка таблицы 2; каждое «Требует уточнения» / «Не рассматривалось» и неназванный приоритет — строка таблицы 3.
- [ ] Числа в п. 3.2 сходятся с таблицей 1.
- [ ] Пустых разделов нет; нумерация разделов сдвинута, если раздел убран, и ссылки «см. п.» указывают на верные пункты.

**Стиль документа**
- [ ] Третье лицо: «Заказчик», «Исполнитель», «Программа». Нет «мы», «клиент», «показали», «ожидал».
- [ ] Нет длительности встреч, «что не рассматривали», оценок и разговорных слов.
- [ ] Нет часов, денег, сроков работ Исполнителя.
- [ ] Нет таймкодов, слов «выписка», «черновик», «Claude», плейсхолдеров `{{…}}`.

**Оформление**
- [ ] Титул без версии и даты.
- [ ] Жёлтым подсвечены: оба названия организаций везде, «Представитель Заказчика» в таблице 3. Больше ничего.
- [ ] В п. 1.4 — должности, без ФИО; руководитель — только если был на встречах.
- [ ] Графа «Срок» в таблице 3 есть; заполнена только названными датами.
- [ ] Собрано на бланке (`tools\build-docx.ps1`): логотип вверху, 1bit.kz внизу, таблицы не заходят на плашку.
