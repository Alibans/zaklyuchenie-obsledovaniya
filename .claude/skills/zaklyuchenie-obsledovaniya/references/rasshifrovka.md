# Если есть только видео или аудио

Claude не слушает записи сам — нужен текст.

## Сначала — проще всего
Спросить пользователя, нет ли расшифровки у платформы встречи:
- **Zoom** — запись в облако → вкладка «Audio transcript» (.vtt).
- **Teams** — в чате встречи «Расшифровка» → скачать .docx или .vtt.
- **Телемост / Яндекс** — «Конспект и расшифровка» в записи встречи.
- **Google Meet** — расшифровка сохраняется в Google Docs организатора.

## Если расшифровки нет — локальная расшифровка
Предложить пользователю поставить инструменты и **ждать его «да»** (ставятся на его компьютер, займут ~1–3 ГБ):
1. Python 3.10+ (`winget install Python.Python.3.12`) и ffmpeg (`winget install Gyan.FFmpeg`).
2. `pip install faster-whisper`.
3. Для каждого файла из `Входные данные\Видео\` — скрипт на Python с моделью `medium` (или `small`, если компьютер слабый), язык `ru`, вывод в `.vtt` в `Входные данные\` с тем же именем.
4. Предупредить: на обычном ноутбуке без видеокарты час записи расшифровывается примерно 30–60 минут; запускать в фоне, по одному файлу.

После расшифровки — проверить пару фрагментов на понятность и вернуться к шагу 0.
