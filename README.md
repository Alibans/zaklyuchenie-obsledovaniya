# Заключение по обследованию: от записей встреч к отчёту клиенту

## Быстрый старт — одно сообщение

Откройте новый чат в Claude Code и отправьте:

> Сделай заключение по обследованию по инструкции https://github.com/Alibans/zaklyuchenie-obsledovaniya

Claude сам скачает комплект, спросит, где лежат расшифровки встреч, и проведёт по шагам. Ниже — подробности, если что-то пойдёт не так.

## Для Claude: тебе дали эту ссылку

Пользователь хочет заключение по встречам с клиентом. Сделай по порядку, не переспрашивая про то, что здесь написано:

1. **Скачай комплект** в `%USERPROFILE%\Documents\Заключения\<Клиент>` (клиента спроси одним вопросом; если пользователь назвал другую папку — туда). Есть git — `git clone https://github.com/Alibans/zaklyuchenie-obsledovaniya.git "<папка>"`. Нет git — PowerShell: `Invoke-WebRequest https://github.com/Alibans/zaklyuchenie-obsledovaniya/archive/refs/heads/main.zip -OutFile $env:TEMP\zo.zip; Expand-Archive $env:TEMP\zo.zip $env:TEMP\zo -Force; Copy-Item $env:TEMP\zo\zaklyuchenie-obsledovaniya-main\* "<папка>" -Recurse -Force` (скрытую папку `.claude` тоже скопировать: `Copy-Item $env:TEMP\zo\zaklyuchenie-obsledovaniya-main\.claude "<папка>" -Recurse -Force`).
2. **Прочитай** `<папка>\CLAUDE.md` и `<папка>\.claude\skills\zaklyuchenie-obsledovaniya\SKILL.md` и работай по SKILL.md. Все пути в нём — от `<папка>`; скрипты запускай с полными путями.
3. **Спроси, где расшифровки** (папка или файлы) и скопируй их в `<папка>\Входные данные\`. Оригиналы не трогать.
4. Скажи пользователю: «Комплект в `<папка>`. В следующий раз можно открыть Claude Code прямо в этой папке и написать „продолжай заключение“».

---

Комплект для Claude Code. Вы кладёте сюда расшифровки встреч с клиентом (демонстрации, интервью). Claude по ним собирает заключение: какие функции клиент использует, как они делаются в 1С и где есть разрыв с требованиями заказчика. На выходе — документ Word.

## Что нужно на компьютере

- **Claude Code** (терминал, VS Code или десктоп) с вашей учётной записью.
- **Git** — чтобы скачать комплект.
- **Microsoft Word** — из него собирается итоговый .docx. Без Word получите отчёт в .html, его можно открыть в Word на другом компьютере.

## Шаг 1. Скачать комплект

Отдельная папка на каждого клиента. В PowerShell:

```
cd C:\Work
git clone <ссылка на репозиторий> "Заключение <Клиент>"
```

Если ссылка не открывается — попросите руководителя добавить ваш GitHub в репозиторий.

## Шаг 2. Положить материалы

Всё — в папку `Входные данные\`:

1. **Расшифровки встреч** — по файлу на встречу. Подходят `.txt`, `.vtt`, `.srt`, `.docx`, `.md`. Текст встречи дают Zoom, Teams, Телемост, Google Meet (включите расшифровку при записи или скачайте её после).
   Имя файла — с датой: `2026-10-15 Демонстрация, часть 1.vtt`.
   **Есть только видео или аудио?** Claude сам по себе запись не слушает. Положите видео в `Входные данные\Видео\` и скажите Claude — он предложит, что поставить для расшифровки, и ничего не установит без вашего «да».
2. **Карточка проекта** — заполните `Входные данные\О проекте.md` (образец уже лежит там). Чем точнее, тем меньше вопросов задаст Claude.
3. **По желанию:** требования клиента, КП, перечень функций из договора, скриншоты старой программы — всё в ту же папку.

Входные данные и результат в git не уходят: это данные клиента, они остаются только у вас.

## Шаг 3. Запустить

Откройте папку комплекта в Claude Code и напишите:

> Сделай заключение по инструкции

Claude прочитает материалы и пойдёт по шагам. Промежуточные файлы появятся в `Результат\`:

| Файл | Что это |
|---|---|
| `01 Опись встреч.md` | какие встречи, кто был, что показывали |
| `02 Выписки\*.md` | по каждой встрече: функция, как сейчас, как показали в 1С, что сказал клиент (с таймкодом) |
| `03 Реестр функций.md` | всё сведено по процессам, с заключением по каждой функции |
| `04 Вопросы.md` | что неясно или не обсуждали — ответить нужно вам |
| `05 Черновик заключения.md` | текст отчёта до сборки в Word |

## Шаг 4. Проверить черновик и ответить на вопросы

На этом шаге Claude **остановится**. Прочитайте `03 Реестр функций.md` и `04 Вопросы.md`:
- ответьте на вопросы прямо в чате или впишите ответы в файл;
- поправьте, если Claude неверно понял, что сказал клиент, — вы были на встрече, он нет.

Потом напишите: **«Собирай документ»**.

## Шаг 5. Забрать результат

`Результат\Заключение <клиент> <дата>.docx`. Перед отправкой клиенту прочитайте его целиком: за содержание отвечаете вы.

## Если что-то пошло не так

- Claude прервался (кончился лимит, закрыли окно) — откройте папку снова и напишите «продолжай заключение». Он продолжит с того, что уже записано в `Результат\`.
- Встреч много (больше 4–5 часов) — Claude обрабатывает их по одной; это нормально, что займёт время.
- Нужна правка в готовом документе — скажите в чате, что поменять; Claude поправит черновик и пересоберет .docx.
- Вопросы по комплекту — к руководителю отдела.
